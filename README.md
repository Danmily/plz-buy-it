# plz-buy-it · 智能挽单

在用户购物犹豫时出手：识别犹豫信号，判断核心顾虑，在关键节点给出差异化挽留动作，用精准的个性化挽留替代一刀切的弹窗优惠。

- **方案文档**：[docs/方案.md](docs/方案.md)（颗粒度、数据准备、模型、挽留内容设计、效果验证、两周排期、业务对接清单）
- **Demo**：[index.html](index.html)，单文件静态页，三段购物会话的逐步回放

## Demo 演示什么

| 用户 | 场景 | 结论 |
|---|---|---|
| A · 降噪耳机 | 领券未用、看低价同类款、回访价格区 | 价格顾虑 → 定向券 + 价格事实 |
| B · 跑鞋 | 反复切尺码、看尺码表、筛尺码评价 | 规格顾虑 → 不发券，给尺码事实 |
| C · 洗衣液 | 复购周期内直达常买款后退出 | 必买 → 不出手，省下挽留券 |

页面中的数字均为示意，未接入真实数据。

## 部署

纯静态页面，无需构建。Vercel 导入本仓库，Framework Preset 选 `Other`，Build Command 和 Output Directory 留空即可，根目录的 `index.html` 即首页。
